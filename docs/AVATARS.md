# Аватары ботов из скриншота

Любому боту Bot HQ рисует блоб (глянцевый «желейный» персонаж) без Blender. Блоб собирается в браузере из короткого
описания: форма, цвет, аксессуар. Описание пишет Grok Bot: ты отправляешь ему скриншот списка ботов, он смотрит на
аватары и дописывает по одной строке на бота в `data/bots.json`. Сервер перечитывает файл примерно за секунду, страницу
перезагружать не нужно: блобы переодеваются на следующем опросе.

## Что отправить Grok Bot

Приложи скриншот списка ботов и вставь этот текст целиком:

```
Это скриншот моего списка ботов. Для каждого бота опиши его аватар и допиши строку в файл data/bots.json.

Формат: одна строка на бота, ключ = имя бота ровно как на скриншоте:
"Имя бота": {"look": {"shape": "...", "color": "#RRGGBB", "accessory": "..."}},

shape, ровно одно из: sphere, rounded_cube, pill, triangle, cone, pentagon, hexagon, star4, star6, clover, rounded_square, trio
accessory, ровно одно из: none, glasses, stem, antenna, bow
color: основной цвет аватара кодом #RRGGBB (не словом)

Бери ближайшую форму из списка, если сомневаешься, пиши sphere. Аксессуар ставь только если он есть на аватаре, иначе none.
Если у бота в файле уже есть запись (floor, chat_url, avatar, color), не трогай её поля, добавь только look.
Не добавляй ботов, которых нет на скриншоте. Файл должен остаться валидным JSON: без запятой после последней строки.
В ответе напиши одной строкой, сколько ботов записал.
```

## Формат `data/bots.json`

Один объект, ключ каждой записи: имя бота (или его id). Одна строка на бота, например:

```json
{
  "Grok Bot": {"look": {"shape": "sphere", "color": "#FC6A14", "accessory": "stem"}},
  "X Writer": {"look": {"shape": "rounded_cube", "color": "#2D84F5", "accessory": "none"}},
  "Warren Buffett": {"look": {"shape": "sphere", "color": "#F6DCC2", "accessory": "glasses"}},
  "Тренды X": {"look": {"shape": "trio", "color": "#F8A41E", "accessory": "none"}}
}
```

Запись `look` может лежать рядом с другими полями бота (`floor`, `chat_url`, `avatar`, `color`):

```json
{"X Writer": {"floor": "x-content", "chat_url": "grokbot://app/v1/agent?id=1", "look": {"shape": "rounded_cube", "color": "#2D84F5", "accessory": "none"}}}
```

### Что значат значения

| shape | как выглядит |
|---|---|
| `sphere` | круглый колобок |
| `rounded_cube` | объёмный кубик с закруглёнными рёбрами, чуть повёрнут |
| `rounded_square` | плоская скруглённая плитка (как иконка приложения) |
| `pill` | вытянутая таблетка |
| `triangle` | скруглённый треугольник |
| `cone` | конус, острая верхушка, плоское основание |
| `pentagon` | скруглённый пятиугольник |
| `hexagon` | скруглённый шестиугольник |
| `star4` | мягкая четырёхлучевая звезда |
| `star6` | мягкая шестилучевая звезда |
| `clover` | четыре пухлых лепестка, цветок или клевер |
| `trio` | три маленьких блоба вместе (цвет: основной, парный и тёмный) |

| accessory | что это |
|---|---|
| `none` | ничего |
| `glasses` | круглые очки |
| `stem` | тёмный черенок сверху, как у плода |
| `antenna` | антенна с шариком |
| `bow` | бантик |

`color` только в виде `#RRGGBB` (регистр не важен, трёхзначные `#abc` не принимаются).

## Как сервер читает записи

Каждое поле проверяется отдельно, одна ошибка не ломает остальное:

- незнакомая `shape` становится `null` (форму тогда выберет хеш от id бота); регистр и `-`/пробелы терпятся: `Rounded Cube` = `rounded_cube`;
- `color` не в формате `#RRGGBB` становится `null`;
- незнакомый `accessory` становится `none`;
- если нет ни годной формы, ни годного цвета, `look` равен `null`.

В состоянии это поле `bots[id].look`. Если у бота нет явного `color`, цветом бота (полоска на доске задач, кружок в списке) становится `look.color`.

## Цепочка аватара в сцене

1. Рукотворный блоб `assets/blobs/<avatar>.glb` (15 демо-ботов). Он всегда в приоритете.
2. Иначе блоб по `bot.look` из `data/bots.json`.
3. Иначе блоб, у которого форма и цвет получены из хеша id бота: одинаковый id всегда даёт одинаковый блоб.

## Проверка

Страница `/scene/blobgen.html` (при запущенном сервере) показывает все формы в разных цветах, аксессуары, блобы без
описания и 15 демо-ботов: рукотворный блоб рядом с собранным из описания (строки в `web/data/demo-looks.json`).
Внизу автопроверка: не больше 6000 треугольников на блоб, структура `blob` / `body` / `eye_L` / `eye_R` / `extra`, повторяемость.
Параметры страницы: `?view=iso|q|front` (ракурс), `?scale=2` (крупнее), `?only=shapes|acc|fallback|demo|office|test`.
