# Обои Grok Bot для Lively Wallpaper

Живые обои: большой белый шар Grok Bot поднимается снизу экрана, глаза следят за курсором, справа карточки
со статусом ботов. Lively показывает **живую страницу с локального сервера** `http://127.0.0.1:8787/face/`:
в самих обоях только маленький `index.html`, который сразу открывает эту страницу. Поменял файлы в репо,
перезагрузил обои: изменения на экране.

Нужно: Windows 10/11, [Node.js 24+](https://nodejs.org), [Lively Wallpaper](https://github.com/lively-community/lively)
(установщик с GitHub или Microsoft Store). Права администратора не нужны.

## Установка (один клик)

1. Двойной клик по **`lively\install.cmd`**. Он:
   - кладёт ярлык в папку «Автозагрузка»: сервер Bot HQ стартует скрыто при каждом входе в Windows;
   - запускает сервер сейчас;
   - собирает `lively\dist\grokbot-wallpaper.zip` (ссылка на страницу с ключом просмотра внутри);
   - если Lively стоит из установщика с GitHub, сразу кладёт обои в библиотеку Lively и включает их на главном экране.
2. Если Lively из Microsoft Store (или не нашёлся), откроется папка с `grokbot-wallpaper.zip`:
   перетащи его в окно Lively (или «Добавить обои» → «Выберите файл»).

Пересобрать только архив: `powershell -ExecutionPolicy Bypass -File lively\build.ps1`
(`-NoShot`: без свежего скриншота для плитки, взять `lively\preview.jpg`).

## Мышь: глаза и карточки

В Lively: **Настройки → Обои → Взаимодействие → Устройство ввода: «Мышь»**. Там же включи
«Взаимодействие мыши когда приложение в фокусе», чтобы глаза следили за курсором и поверх открытых окон.
(В свежем Lively это включено по умолчанию.)

- Глаза идут за курсором; без мыши шар сам оглядывается и моргает.
- Карточки перетаскиваются мышью прямо на рабочем столе, место запоминается.
- Значки рабочего стола остаются поверх обоев и кликаются как обычно.
- **Спрячь значки рабочего стола**, если мешает рамка: правый клик по рабочему столу → Вид → снять
  «Отображать значки рабочего стола». Lively только повторяет клики для обоев, а настоящий клик получает
  рабочий стол Windows: со значками перетаскивание карточки заодно рисует синюю рамку выделения.

## Настройки: цвет бота и твои боты

В библиотеке Lively правый клик по Grok Bot → **«Настроить обои»** → «Цвет бота»: White или Black.
Lively передаёт выбор странице сразу и помнит его после перезагрузки обоев.
Там же «Your bots channel»: канал ntfy.sh твоих ботов, тогда обои показывают их вместо демо (имя канала работает как пароль, не публикуй).

## Несколько мониторов

`install.cmd` ставит обои на главный экран. Чтобы на всех: **Настройки → Обои → Способ размещения**:
«Копировать» (одни обои на каждом экране) или «Перекрывать» (одна страница через все экраны).
Либо в режиме «Экран» выбери обои Grok Bot для каждого монитора отдельно. На вертикальном мониторе
шар стоит внизу, карточки справа сверху.

## Как применяются правки

- `web\face\*` и `assets\face\*`: сохрани файл и **перезагрузи обои**. Сервер отдаёт их без кэша (`--no-cache`),
  поэтому новая версия приходит сразу.
- Перезагрузить: `lively\reload.cmd` (Lively из установщика) или в библиотеке Lively правый клик по Grok Bot →
  «Установить обои».
- Статусы ботов (`/api/state`) обновляются сами каждые 2 секунды, перезагрузка не нужна.
- Правки в `server\`: перезапусти сервер: `lively\uninstall.cmd`, затем `lively\install.cmd`.
- Свой журнал ботов вместо `data\events.jsonl`: переменная среды пользователя `BOTHQ_JOURNAL=путь`, потом
  перезапуск сервера. Другой порт: `BOTHQ_PORT` (потом снова `install.cmd`, чтобы ссылка в архиве обновилась).

## Удаление

Двойной клик по **`lively\uninstall.cmd`**: убирает ярлык из автозагрузки, останавливает сервер, который
запустил автозапуск (чужой dev-сервер на том же порту не трогает), убирает обои из библиотеки Lively
(если их ставил `install.cmd`) и удаляет `lively\dist`. Если ставил zip вручную: в Lively правый клик по
Grok Bot → «Удалить». Репо и `data\` остаются.

## Безопасность

В `grokbot-wallpaper.zip` и в библиотеке Lively (`index.html`) лежит ссылка с ключом просмотра из
`data\view-key.txt`; Lively ещё пишет её в свой лог (`%LOCALAPPDATA%\Lively Wallpaper\logs`).
Ключ открывает дашборд на просмотр. Архив в `.gitignore`: не выкладывай и не пересылай его.
Сменить ключ: удали `data\view-key.txt`, перезапусти сервер (`uninstall.cmd`, `install.cmd`).

## Если что-то не так

- Вместо шара окно пароля: ключ в ссылке старый. Запусти `install.cmd` ещё раз и переустанови обои.
- Чёрный экран или «не удаётся открыть»: сервер не запущен. Проверь `http://127.0.0.1:8787/healthz`
  в браузере (должно быть `ok`), лог: `data\autostart.log`.

## Файлы

| Файл | Что делает |
|---|---|
| `install.cmd` / `install.ps1` | автозапуск сервера + сборка архива + установка в Lively |
| `uninstall.cmd` / `uninstall.ps1` | всё обратно |
| `server.ps1` | скрыто запускает сервер, если порт ещё не отвечает (его зовёт ярлык автозагрузки) |
| `build.ps1` | собирает `dist\grokbot-wallpaper.zip` с ключом |
| `reload.cmd` | перезагружает обои в Lively |
| `LivelyInfo.json` | описание обоев для Lively (веб-обои: `index.html` открывает живую страницу) |
| `LivelyProperties.json` | настройки в «Настроить обои» (`botColor`), страница получает их через `livelyPropertyListener` |
| `preview.jpg` | картинка для плитки, если свежий скриншот не получился |
